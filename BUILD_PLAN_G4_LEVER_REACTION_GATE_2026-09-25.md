## Purpose

G3 answers **which visual objects are levers** by completing the click/collision sweep. G4 answers
**what each proven lever does**. It must eventually let Duck describe a lever as a human would:
the intervention, affected subject or region, visible transformation, repetition law, limits,
conditions, couplings, and a prospective demonstration. A label alone is not understanding.

G4 receives only G3 entities in `G4-READY`. Scoped nulls and bounded unknowns do not become G4
subjects. The counter mask remains active, and all claims stay bound to lossless executed evidence.
The win is never guessed. It may only be observed while the world physics is explored.

Cross-level memory and the decision about what carries from level N to level N+1 are separate
capabilities. A level boundary may interrupt a G4 experiment without becoming part of lever typing.
That interruption is retained as evidence and deferred to the cross-level transfer work at G9; it
does not redirect the G4 CLICK build ladder.

## Ordered slices

1. **G4.0 binding and G4.1 effect anatomy.** Bind the accepted G3 intervention, witness,
   confirmation, dossier, member, and entity. Partition every non-counter changed cell into exact
   local or remote spatial channels. Require Duck to name every channel and state every observed
   integer rewrite in prose.
2. **G4.2 repeated activation and orbit discovery.** Activate each confirmed lever repeatedly.
   Continue while each activation reveals a new counter-masked grid state. Return from that lever
   when an activation produces no masked change or revisits a prior masked state. Record the
   observed sequence and recurrence; do not force a final mechanism label at this rung.
3. **G4.3 limits, persistence, and reversal.** Find fixed points, capacity, reset behavior,
   persistence across unrelated actions, and any inverse intervention.
4. **G4.4 conditions.** Vary position, state, order, contact direction, and other visible context to
   identify necessary and sufficient preconditions without promoting silence to inertness.
5. **G4.5 couplings.** Test whether this lever changes other levers, gates, paths, hazards,
   resources, or the ego. Record directed dependencies and jointly changing responders.
6. **G4.6 human mechanism explanation.** Compress the evidence into a stable rule using the
   flip-book transformation vocabulary while retaining uncertainty and alternative models.
7. **G4 exit demonstration.** Freeze a novel prediction derived from that rule, execute it later,
   and grade the scoped result. Emit a versioned reaction-law product only after support.

Any newly appearing visual object reopens G3 for that object before its own G4 subtree begins.

## First-slice contract

The first slice reuses G3 evidence and performs no new game action. For each G3-ready lever it must:

- retain entity, member, intervention, witness, supported confirmation, accepted dossier, and mask;
- reject every G3 scoped null from the G4 subject set;
- account for every residue cell exactly once and for no counter cell;
- group affected cells into connected local/remote regions;
- retain exact coordinates, bounding boxes, before/after integer counts, and signed arithmetic;
- expose a compact automatic card and a callable full `reaction` view;
- require Duck to explain each region and exact integer rewrite, with a competing model and
  falsifier;
- explicitly leave repetition, reversal, conditions, couplings, and prospective demonstration open.

The slice exits when the frozen vc33 v8 evidence binds exactly E0004 and E0005, excludes all eight
scoped null entities, compiles complete anatomy for both, and the active gate accepts a substantive
answer for each. Passing schema validation without using the channel facts is a failure.

## G4.2 governing activation law

The repository mine confirms direct prior art:

- V4 `library/cycle_probe.py` hashes the full grid after masking the life counter, HUD, and known
  counter cells. Adjacent equality detects a null press; equality with any earlier non-adjacent
  state detects an observed recurrence.
- V4 `cybernetic/state_tracker.py` treats first-seen masked configurations as novel and exact
  repeats as non-novel while retaining the action edge.
- Golden `BUILD_OUTLINE_v1_2026-09-05.md`, G4-03, states the descent floor as: **return when presses
  repeat instead of reveal; no threshold**.

The active G4.2 contract therefore is:

1. Take the G4.1 intervention for the current confirmed lever.
2. Record the current counter-masked full-grid fingerprint as orbit state `S0`.
3. Activate that same lever again and record its exact attributed effect plus the next masked
   fingerprint.
4. Continue while the fingerprint is new.
5. Stop that lever's descent on the first counter-masked null transition or first exact recurrence.
6. Record the full fingerprint sequence, effect sequence, recurrence indices, and observed period.
7. Move to the next confirmed lever. A new visual object first opens entity-specific G3.

A null result means only `NULL_AT_OBSERVED_STATE`. A recurrence means only
`OBSERVED_STATE_RECURRENCE(period=N)`. Neither licenses global saturation, eternal determinism, or
a final toggle/cycle law. G4.3 and G4.4 test limits, reversal, persistence, and conditions. A hard
runtime or action budget is a safety boundary and yields `UNRESOLVED_BUDGET_STOP`; it is never an
epistemic completion rule.

E0005 later crossed a level boundary. That event neither completes nor falsifies its lever type.
It is an interrupted observation for the future cross-level lifecycle and is outside the closure
criteria of the next G4 CLICK slice.

The active target is G4.3 for CLICK levers. Starting from an observed G4.2 stop, it asks only:

1. does one immediate repeat confirm the observed fixed point;
2. does the state persist through an available unrelated intervention;
3. can another already-confirmed lever reverse or release it; and
4. after reversal, can the original lever produce its effect again?

These observations support scoped claims about an observed endpoint, persistence, and an available
inverse. They do not decide what knowledge transfers to the next level.

The implemented G4.3 evidence kernel and gate adapter are documented in
`BUILD_SLICE_G4_3_LIMITS_PERSISTENCE_REVERSAL_2026-09-26.md`. The controller requires the second
endpoint null, keeps optional persistence controls separate, and accepts exact reversal only when
another confirmed lever restores an earlier G4.2 state and the original lever becomes effective
again. G4.2 now hands off each completed lever locally while retaining other lever ids as pending.
The full offline suite passes 360 tests with the online/native suites excluded.
