## The project in one paragraph

Ring 9 is building an evidence-backed semantic library for each novel ARC world. The gates turn missing library entries into bounded experiments. Deterministic code performs routine coverage, records every transition, and certifies only conclusions supported by receipts. Duck reads a short view of the library and chooses among gate-admitted experiments when judgment helps. G1 identifies the control locus, G2 the counter, G3 the lever roster, G4 studies each lever, and later chapters describe forces, driven reactions, scoped negatives, and typed physics laws. A level clear is useful evidence; library quality is the primary product. Push is shelved.

## Terms that must stay distinct

- **Gate record:** the source of certified belief.
- **Canonical library:** persisted, validated `world_model.json`; one writer.
- **Live view:** bounded in-memory projection for Duck; it cannot write the canonical file.
- **GATED action:** admitted by the active gate and eligible for that gate's evidence rules.
- **FREE_PLAY action:** fallback action with a receipt; it is never relabelled as gated evidence later.
- **ACCOUNTED:** every observation and gap is represented.
- **CHARACTERIZED:** roles and recurring changes have supported explanations or named residuals.
- **FILLED:** all questions in the declared observation scope are closed with evidence or coverage certificates.

## Rules that do not bend

- Duck's assertions carry no authority.
- One attributed activation with masked residue admits a lever; G4 deepens its dossier.
- The gate owns admission and certification. The agenda, digest, and grammar are projections.
- Evidence never leaks across games, levels, or lives without an explicit, testable bridge.
- Push remains shelved. The library itself is the cybernetic target.
- Historical documents remain history. Add a new version when a dated plan or status changes.
- No Kaggle result counts until the feature is proven to have run and its artifacts are inspected.
