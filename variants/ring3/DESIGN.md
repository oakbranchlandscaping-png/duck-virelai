# RING 3 DESIGN — THE FRONTIER MADE EXPLICIT
**v1 · 2026-08-26 · on the Director's go · the win-novelty logic mechanized**

## Three capabilities, one variable vs ring25

1. **The frontier navigator.** The digest LEADS with where the win can be: untried
   actions across visited states, and — because the world is a fixed deterministic
   graph whose walked edges are witnessed transitions — the shortest KNOWN route from
   the current state to the nearest frontier state, computed by BFS over recorded
   edges only. This is routing over the walked map (replaying witnessed presses),
   NOT world reachability: no terrain is assumed, no ground/wall labels are used —
   Rung 3.5's fence (Director's amendment) is untouched. Routes are advisory
   ("observed destinations; hidden state may divert"); long routes print truncated
   LOUDLY. Untried-at-a-visited-state is roster-minus-tried, labeled as such (the
   exact valid list is known only at the current state — stated, not hidden).
2. **The ego-coupled drain seal** (the ls20 finding mechanized). A churn region R
   (not counter-sealed) seals DRAIN(ego-motion) iff: ≥2 edges where a sealed ego
   MOVEd and R ticked on ALL of them; ≥2 edges where no ego moved and R held on ALL
   of them. Pure counts, ∀-shaped both ways, one violation kills, recomputed each
   turn. Teaching: "[DRAIN] the region at .. ticks exactly when you MOVE — moving
   costs it; blocked and non-move presses are free."
3. **Sealed [LEVER] attribution — CLICK-scope only this ring.** With counter masked
   and (on CLICK worlds) no ego, a located click on component O followed by world
   change is a lever WITNESS: LEVER is existential — one witness seals, later silence
   never retracts (canon 2 §6.2). Record per target (worldline id when the weave has
   it, else class+bbox): witness count, effect summary (cells changed elsewhere,
   class transitions). NAV-world lever attribution (contact-mediated) is NOT built —
   it needs the ego-contact read; named for a later ring, not attempted.

## Pre-registered fixtures for the single validation run

CLICK worlds: [LEVER] seals appear with sane targets/effects; [FRONTIER] lines present
with routes; zero [DRAIN] seals (no ego). NAV worlds with sealed ego + fuel (ls20):
[DRAIN] seals on the bar; frontier routes used (transcripts show the model following a
suggested route at least once — soft fixture). Counter worlds: [DRAIN] must NOT seal
on counter-sealed regions (exclusion control). cn04-class (ego, no score): watch
whether frontier-led digest reduces its wandering (526 actions last run — the number
this ring targets).

## Failure shapes filed

Route advisory can mislead where hidden state diverts a replayed press (routes are
labeled advisory; a diverted route is model-visible via the map). Roster-minus-tried
overstates untried where a state's true valid set is smaller (labeled). A driven
object clicked once with coincident unrelated world change false-seals LEVER (∃ law
accepts it; the effect summary lets the model doubt it; lever un-typing is a later
rung's discriminate).
