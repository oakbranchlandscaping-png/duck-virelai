## 1. Product and order of knowing

The product remains an evidence-backed semantic library for each observed level of each novel world. The immediate priority is now explicit:

1. describe the visual world in detail;
2. express its observed changes in a stable internal language;
3. promote supported changes into scoped mechanic laws;
4. use that language to explain an observed win;
5. freeze the explanation and test it on the next level.

The solver must produce a useful description on a level that never clears. A win explanation is downstream of the ordinary world model and may introduce no ungrounded noun, verb, identity, relation, or condition.

## 2. The internal language

### Nouns

The six archetype roles are EGO, COUNTER, LEVER, ENVIRONMENTAL FORCE, REACTIVE-DRIVEN, and INERT. Terrain and unresolved visual objects remain observations rather than invented roles. Roles are set-valued except that INERT is exclusive. A class change reopens the old role set.

### Observation verbs

The base visual alphabet is `STILL`, `RECOLOR`, `MOVE`, `GROW`, `SHRINK`, `BIRTH`, `DEATH`, `DEFORM`, and `AMBIGUOUS`. Each event carries exact before and after state, spatial or class delta, level, life, transition, and correspondence evidence.

These verbs describe what happened. They do not assign a cause.

### Relations and causal laws

A gate may promote observed events into relations such as activates, changes, drives, blocks, releases, resets, increments, or decrements. The promoted sentence must state its intervention, subject, affected objects, transformation, conditions, scope, evidence, limitations, and prospective status.

### Unknowns

Unresolved identity, unexplained change, untested intervention, inconclusive attribution, reachability limit, budget limit, contradiction, and record mismatch are first-class language elements. The description does not become fluent by hiding its gaps.

## 3. Canonical artifact

Extend the single canonical `world_model.json` to schema v3. The gate record remains the source of certified belief. The census compiles observations, gate products, and receipts. The agenda, Duck view, world report, and grammar renderer are read-only projections.

Each level must contain:

- objects and worldlines, present and departed;
- a descriptive event ledger for every recorded transition;
- certified nouns and unresolved noun questions;
- per-lever G4 dossiers;
- forces, driven reactions, scoped negatives, and inert certificates when later gates earn them;
- typed causal sentences and their prospective results;
- a deterministic scene description and unexplained residual list;
- observed-win and transfer chapters only when an actual win occurs.

No legacy or shadow compiler may write the canonical artifact.

## 4. Description ladder

### D0 — exact scene and event description

Compile every transition from accepted continuity and pixel arithmetic. Attach an archetype noun only when a gate certified it. Otherwise use the track identity and an explicit unresolved role.

### D1 — lever-centered causal description

G3 supplies the roster. G4 studies each lever and fills anatomy, orbit, relations, repetition law, conditions, contradictions, and limits. Only receipt-backed G4 products turn coincidence into a cause.

### D2 — complete archetype description

G5/G6 add environmental forces, driven responses, scoped negatives, coverage certificates, and INERT. Every recurring visible change receives a supported explanation or a named residual.

### D3 — executable physics grammar

Compile immutable typed sentences from certified products. Each sentence is grounded in evidence, serializes deterministically, declares required information, and carries prospective status. Rendering prose never changes its meaning.

### D4 — observed-win explanation and transfer

When the environment presents a terminal level transition, bind it to the frozen pre-win library. Describe the win using existing nouns, verbs, relations, and conditions. Separate the final action from the earlier configuration that made it succeed. Freeze the level-N sentence before testing level N+1.

## 5. Cybernetic loop

The earliest actionable library gap selects the gate. The gate owns its admissible experiments. The controller performs routine coverage and navigation. Duck chooses among bounded experiments when judgment helps. Receipts record the outcome. Deterministic code updates the canonical language, and Duck reads the new revision.

The full census stays off the controller's per-action path. Gate-state questions remain cheap; detailed description is compiled for Duck turns, level boundaries, terminal paths, and reports.

6. **Current-source public 25:** inspect descriptions, artifacts, latency, handoffs, gaps, and errors.
7. **G5/G6:** forces, driven reactions, negatives, Band 1, and inert certificates.
8. **Typed grammar:** accepted expression schema, grounding, and prospective tests.
9. **Observed-win transfer:** frozen explanation, next-level correspondence hypotheses, prediction, and referee verdict.
10. **Recovery and release:** library-guided fallback, bounded submission-only context restart, rehearsal, freeze, and submission.

Independent owners may overlap disjoint files, but win transfer cannot precede an accepted ordinary world description.

## 7. Acceptance

The description milestone closes when, on replay and live artifacts:

- every observed object and transition is represented once;
- every transformation has a typed verb and resolvable evidence;
- certified nouns come only from gate products;
- causal language comes only from attributed interventions or prospectively tested gate products;
- contradictions and unexplained changes remain visible;
- Duck can retrieve the scene, object history, transformation, dossier, law, and gap pages under hard budgets;
- the renderer produces the same description from the same validated JSON;
- a non-winning level receives a detailed useful description;
- no description code mutates gate state or creates a second belief writer.

The observed-win milestone then requires a winning transition to be explained entirely in the frozen internal language and tested prospectively on the next level.

Push and frontier-driven win seeking remain shelved.
