## The strategy, whole

**1 · The physics grammar is deduced through targeted probing.**
The agent does not guess. It probes in lawful order — ego first (what covaries with
WHICH action), counter second (what ticks on ANY action; characterized, quarantined
from attribution, never unwatched), then the lever hunt (everything presumed a lever
until the world acquits it). Each press is chosen to reveal; pressing stops when
presses repeat. The library is built with the weave and the semantic roles: deltas →
objects → worldlines → verbs → mechanics → roles, each rung a compression of the one
below, every belief walkable back to the recorded deltas that earned it.

**2 · The win is found through exploration of new states.**
The root is the same — RESET returns the identical start state every time, for
everyone, so no branch is ever lost and deep frontiers stay cheaply reachable. The
frontier is a combination of actions — every untried action at every reached state is
an unvisited region of the same fixed graph. **The win must exist outside the seen
states:** every visited state is proven non-win by the run's own continuation, so the
win lives, by logic and not by hope, in what the map marks untried. Stale-state
tracking is therefore the soundness of the search itself. The grammar prunes the
frontier; the root makes it re-reachable; exploration exhausts it until a win is SEEN
— stumbled into, never guessed. (Corollary: an exhausted frontier with no win seen is
a sound verdict that the grammar is missing a variable — diagnostic, not defeat.)

**3 · Once found, the win is described in the terms of the physics grammar.**
Only an observed win can be described; only a described win can be attempted. The
description is a predicate over the grammar's objects and mechanics — what was
reached, aligned, consumed — never a memorized action sequence (the routes are a set;
the win is a state; a route is a witness, not the object).

**4 · The described win is attempted on the next world.**
The rule becomes a live hypothesis wherever it is next applicable — established
directly, in few presses, killed and re-learned where it fails.

## ⚠ ONE RULING SURFACED, NOT RESOLVED (chamber flag, per never-invent-doctrine)

§4 says "the next WORLD." The canon's Tier-1/Tier-2 falsification split
(SPEC_SOLVER_LOOPS §7; canon 1 §6) carries the win-predicate LEVEL to level within a
game, and wipes all content at the game wall — only machinery crosses worlds. The
Director has stated "next world" twice, which this chamber reads as a possible ruling
that the win DESCRIPTION — stated purely in the grammar's invariant vocabulary (roles
and verbs, no colours, no coordinates, no world content) — is machinery-grade and may
cross the wall as a hypothesis-shape prior ("wins here tend to look like: counter at
extremum / ego occupying target region / all members aligned"). That is a real
doctrinal extension: canon 1 §9 forbids win-proximity priors BEFORE a first win, and a
carried win-shape is exactly such a prior on the next world. Options as the chamber
sees them: (a) "world" means the next level's world-state — no extension, text stands
as canon; (b) the invariant-shape carry is ruled legal FOR THE HYBRID ONLY (instrument
ruling shields the golden build); (c) it is ruled legal generally — a canon amendment
owed to the golden chamber. **Held at (a)+(b)-pending until the Director rules; nothing
is built on (c).**
