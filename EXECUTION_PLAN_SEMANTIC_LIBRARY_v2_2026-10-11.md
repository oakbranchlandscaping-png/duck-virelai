## 1. The one loop to build

The semantic library is Duck's internal world model. Each turn it exposes a current **knowledge target** from an actionable gap. The gate states which experiments are admissible; Duck chooses among them when interpretation matters, while the controller performs routine coverage. The action is recorded; deterministic code updates certified claims or typed gaps; the next library revision guides the next choice. A model statement alone never certifies a role, mechanism or law.

The current gate IDs stay as implemented: **G1 ego/control locus, G2 counter, G3 witnessed lever roster, G4 per-lever study**. One attributed activation with masked residue puts a lever on the roster. G4 reads that roster and works each lever's effects, states, repeat behavior, mechanism and conditions into its dossier. Later gates cover forces, driven reactions and scoped negatives.

A win found during this investigation is recorded as an observation. The agent describes it in typed visual-object and verb terms, freezes that claim before seeing the next-level result, and tests whether it transfers. Cross-level object matches begin as hypotheses. This builds a predictive library without adding the shelved Push or a win-seeking action policy.

## 5. Shared interfaces and stop rules

- **One canonical model:** `world_model.json` v2 is the persisted library in gated mode. The live view compiles through the same census and validator but is never persisted as `LIVE_VIEW`. The report and Duck-facing digest are projections, not belief stores.
- **One target:** the library proposes the current actionable gap; the gate card authorizes the experiment. They must agree. `NOT_BUILT`, a failed foundation and an untestable gap are shown as limitations, never as actions Duck can perform.
- **One lever roster:** G3's witnessed entities feed G4's worklist. A lever's first witness certifies existence, while repetition, effect and conditions are separate G4 claims. Ambiguous attribution stays `INCONCLUSIVE`.
- **One evidence rule:** GATED and FREE_PLAY receipts remain distinct. No later label upgrades a free-play action. Every cited transition belongs to the same game and level, and the action record reconciles with harness execution.
- **One transfer boundary:** the level-N win sentence is immutable before the next-level test. Carry is a hypothesis; no cross-level object identity or law is certified by visual resemblance alone.
- **Runtime friction budget:** a slice that adds Duck prompt text or per-turn census work reports rendered size, median/tail latency and action yield. It must preserve the binding card and avoid unbounded retrieval or repeated unchanged prose.
