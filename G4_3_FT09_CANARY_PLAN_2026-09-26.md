## Required G4.3 recurrence slice

The current G4.3 implementation consumes `NULL_AT_OBSERVED_STATE` orbits. ft09 is expected to
exercise `OBSERVED_STATE_RECURRENCE`, so launching it as a full G4.3 test now would intentionally
reach an unsupported branch.

For an observed period-N return, the next slice must:

1. retain the exact G4.2 state sequence and recurrence indices;
2. continue the same confirmed lever for exactly one observed period;
3. compare every new counter-masked address with the predicted next address in the orbit;
4. emit `EXACT_RECURRENCE_RECONFIRMED` only if the whole additional period matches;
5. emit `RECURRENCE_DIVERGED` at the first mismatch and preserve that state for G4.4 conditions;
6. keep a fixed action count as an execution plan, not as evidence—the expected period comes from
   the observed recurrence;
7. require Duck to explain the finite observed recurrence and its scope before advancing.

For a period-2 recurrence, G4.2 supplies the first return and G4.3 observes one additional complete
two-action period. This meets the prior-art two-period confirmation floor.
