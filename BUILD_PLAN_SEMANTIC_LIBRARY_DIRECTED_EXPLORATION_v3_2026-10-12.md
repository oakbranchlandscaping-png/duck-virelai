## 1. Product

The product is a versioned, evidence-backed semantic library for every observed level of every novel world. It is the agent's internal world model and the target of the cybernetic loop.

An empty library is bad. A useful library accounts for the observed objects, attaches evidence-backed roles, opens the right deeper questions for each role, and records exactly what remains unknown. A full library is good only within its declared observation scope. The solver acts to answer its earliest actionable library question.

The canonical persisted artifact is `world_model.json`. The gate record supplies certified belief. The live view, agenda, card, human report, and physics grammar are validated projections; none may become an independent belief writer.

## 2. Control loop

1. The validated library exposes its earliest actionable gap.
2. The responsible gate owns the admissible experiment set.
3. The controller performs routine coverage and navigation.
4. Duck chooses among bounded admitted experiments when judgment helps.
5. Every action receives a receipt and transition record.
6. Deterministic code certifies only what the evidence supports.
7. The library revision changes, and Duck reads the new state before choosing again.

The card, agenda, selected probe, route target, receipt, transition row, and digest must name the same question. If Duck times out or declines, the controller resumes coverage without waiting.

## 3. Gate-to-library contract

The code's numbering remains authoritative:

| Gate | Library target | Completion meaning |
|---|---|---|
| G1 | control locus / ego | the control surface and embodied footprint or pointer binding are certified, or the unresolved condition is typed |
| G2 | counter | the counter binding and observed behavior are certified, or the gap is typed |
| G3 | lever roster | each admitted lever has one attributed activation with masked residue; null, inconclusive, unreachable, and untried rows stay distinct |
| G4 | lever dossiers | each lever is studied for anatomy, orbit, relations, law, conditions, contradictions, and limits |
| G5/G6 | remaining physics chapters | forces, driven reactions, scoped negatives, inertness certificates, and residual dynamics are recorded |

One G3 witness is enough to enter a lever in the roster. Repetition and mechanism belong to G4. Duck's statement alone never fills a field.

## 4. Library structure

Each observed level contains:

- a complete object and transition census, including departed objects;
- evidence-scoped roles and identity joins;
- gate products and receipts;
- a roster of levers and one dossier per lever;
- forces, driven reactions, negatives, and coverage certificates when built;
- typed physics sentences that connect visual objects, verbs, conditions, and outcomes;
- contradictions, residuals, reachability limits, budget limits, and unanswered questions;
- an observed-win record and cross-level transfer test when a win occurs.

Statuses remain distinct:

- **ACCOUNTED:** every observation and missing conclusion is represented.
- **CHARACTERIZED:** roles and recurring changes have supported explanations or named residuals.
- **FILLED:** all questions in the declared scope are closed through evidence or a coverage certificate.

A later contradiction reopens the affected dossier.

## 5. Model role

Duck receives a short goal, the relevant library facts, and the admitted choice. It uses visual judgment and hypothesis formation where deterministic coverage cannot decide cheaply. It should finish a turn with one admitted choice or action request. The controller owns routine steps and the gate owns certification.

The controller path uses a cheap gate-state question view. The full census is built for Duck turns, level boundaries, terminal paths, and reporting. It must not be recomputed before each controller action.

## 6. Observed-win learning

World study may produce a level clear. When it does:

1. record the winning before-board, action, after-board, objects, level, life, and receipt;
2. describe the event in the internal language of roles and verbs;
3. separate demonstrated facts from hypotheses;
4. freeze the level-N sentence before viewing the next level's result;
5. identify candidate corresponding objects in level N+1;
6. predict what the frozen sentence implies;
7. run an admitted comparable test and grade success, failure, or non-comparability;
8. retain, narrow, or revoke the rule.

This is transfer from an observed win. It does not turn winning into the exploration objective.

## 7. Explicit scope decisions

- Push, frontier-driven win seeking, and the Push handoff are shelved.
- Free play is a fallback only after no gate can act. Its goal is the best actionable library gap.
- FREE_PLAY receipts never become GATED evidence after the fact.
- Runtime recovery may restart Duck's context under ruling 24; it may not alter the evidence boundary.
- Cross-game evidence may suggest a hypothesis but cannot certify another game's world.
- Terrain observations are not automatically semantic roles.
- G3 entity IDs own G3/G4 question identity; track joins supply visual context when exact.

## 8. Staged path

### Stage A — shorten and stabilize the development loop

Create measured T0/T1/T2 test tiers without reducing coverage. Close NAV G1 stalls and rejected-answer loops. Preserve one full acceptance floor before packaging.

### Stage B — finish lever-centered study

Extend the schema to v3 with one per-lever dossier. Project G4 accepted answers and in-progress state into explicit chapters and receipts. Let Duck select the next eligible lever question while the controller executes the bound work.

### Stage C — prove the current solver live

Run the accepted current source over all 25 public worlds once. Require a canonical model for every observed world and level, per-world accounting, selection events, errors, latency, and a rendered report from the same JSON.

### Stage D — complete the physics grammar

Build G5/G6 products, full role coverage, forces, driven reactions, scoped negatives, typed laws, prospective tests, and explained-share metrics.

### Stage E — learn from observed wins

Add the winning-transition record, frozen typed sentence, next-level mapping, prospective prediction, and referee verdict.

### Stage F — recovery and release

Add bounded submission-only Duck restarts, run the full rehearsal, freeze the source and keys, and prepare the scored submission and paper evidence package.

## 9. Acceptance criteria

The library-centered solver is ready when:

- every observed level has a validated canonical artifact;
- every action has a matching provenance path or a typed record mismatch;
- Duck's displayed goal matches the gate's admitted target;
- each lever has a visible dossier and a disposition for every applicable chapter;
- all remaining changes and roles are explained or typed as gaps;
- the current public-25 run completes with bounded prompt size and usable turn latency;
- no false lever or unsupported role is certified;
- the human report is rendered from the canonical artifact;
- the full test and package gates pass from the committed source.

Score and clears remain reported outcomes, not substitutes for library completeness.
